## How to Build & Publish Future Releases
1. Ensure `main` is clean and all checks (`spotlessCheck`, `detekt`, unit tests, `lintRelease`) pass.
2. Export `PHOTX_KEYSTORE_PATH`, `PHOTX_KEYSTORE_PASSWORD`, `PHOTX_KEY_ALIAS`, and `PHOTX_KEY_PASSWORD` in your shell.
3. Run `.\gradlew.bat :app:assembleRelease --no-daemon --max-workers=2`.
4. Verify with `apksigner verify --verbose --print-certs` and `aapt2 dump badging`.
5. Rename `app/build/outputs/apk/release/app-release.apk` to `PhotX-<version>.apk` and generate `SHA256SUMS.txt`.
6. Tag `main` with an annotated tag (`git tag -a v<version> -m "..."`), push the tag, and publish with `gh release create v<version> PhotX-<version>.apk SHA256SUMS.txt --prerelease`.

## Installation & Update Instructions
1. Download `PhotX-0.1.0-beta.1.apk` and `SHA256SUMS.txt` from GitHub Releases.
2. Verify the APK SHA-256 checksum matches `SHA256SUMS.txt`.
3. Install on an Android device (API 26+). Note: if an older **debug** build is installed, Android will reject an in-place update because the debug certificate differs from the beta signing key; do not wipe an active session unless switching intentionally.
4. Open PhotX, sign in with Telegram, and grant requested media permissions.

## Known Limitations
- Cloud video streaming and cloud video restoration are not implemented yet (images only).
- Private beta build; some advanced connectivity/error edge cases require further field testing.
- Physical-device validation was not run in this session (verified on `PhotX_API_36_x86_64` emulator).
