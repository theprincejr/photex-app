## What's New Since `v0.1.0-beta.1`
- **Phase 4.3 — Folder-Wise Automatic Backup:**
  - Discover all Android device media folders (`DeviceFoldersScreen` under **Backup → Back up device folders**).
  - Toggle automatic backup ON/OFF per folder (new folders default to OFF).
  - Automatically queues existing eligible and newly scanned media in enabled folders while preserving manual user selections (`QueueOrigin.MANUAL` vs `FOLDER_AUTO`) and cloud copies when disabling a folder.
  - Room `version = 2 -> 3` migration (`MIGRATION_2_3`).
- **Critical Bug Fixes:**
  - **Gallery Thumbnails & Partial Access:** Live `TdApi.GetMessage` thumbnail resolution (`TelegramThumbnailSource`), Telegram `minithumbnail` fallback (`.mini.jpg`), stale `local_thumb_path` invalidation/re-fetch, and Coil `onError` fallback icon instead of grey placeholders.
  - **Cloud-Only Photo Viewer:** Pre-subscribed TDLib `DownloadFile` progress/completion tracking, Coil `onLoading`/`onError` state handling, `4096px` / `allowHardware(false)` decode bounds for high-resolution device photos, and Retry recovery instead of black screens.
